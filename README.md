# explainable-emotion-music-recommendation

##University of Surrey - MSc Data Science Dissertation 


A music recommendation system that predicts a listener's emotional state (valence–arousal) from acoustic features and recommends songs matching or shifting that mood, with an explainability layer surfacing which audio characteristics drove each recommendation. Built on the DEAM dataset (openSMILE acoustic features, XGBoost regression) and validated against real-world listening data collected via a custom browser plugin.
